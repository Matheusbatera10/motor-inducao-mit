# Revisão de MIT

Site de estudo de Motores de Indução Trifásicos, baseado no Capítulo III da disciplina Aplicação de Máquinas Elétricas.

- **Guia de revisão:** como explicar cada tema, o que guardar, pegadinhas e cards.
- **Questões:** discursivas, de marcar e de cálculo, com progresso salvo no navegador.
- **Fórmulas:** resumo com o significado de cada variável, pronto para imprimir.
- **Capítulo III:** teoria completa com simuladores e explorador 3D.

## Rodar

```bash
npm install
npm run dev
```

## Verificar

```bash
npm run build
npm run lint
```
